# Перевірка форми заявки через Playwright MCP

- **Запит (дослівно):** «Відкрий http://localhost:3000, заповни форму заявки тестовими даними, відправ, перевір консоль і мережу. Інших адрес не відкривай.»
- **Сесія:** `claude --permission-mode default`, у `/mcp` лише `playwright` (Supabase вимкнено), Claude Code 2.1.296, Opus 5.5, effort high; індикатор «manual mode on». Застосунок — `npm run dev` цього репозиторію на `http://localhost:3000`; перед запуском порт звільнили від чужого сервера, перевірено `GET /` → 200 і `<title>LeadDesk</title>`.
- **Ланцюжок інструментів:** із запису читається перший виклик — `browser_navigate` з `url: "http://localhost:3000"`; діалог схвалення «Do you want to proceed? 1. Yes / 2. Yes, and don't ask again… / 3. No». Агент підсумував, що всього було 6 викликів `playwright`; імена решти викликів у записі нечитабельні, тож їх не наводжу. Сесія також виконала одну shell-команду `git status --short && git check-ignore -v .playwright-mcp`; діалог «This command requires approval» був.
- **Чи відправилась форма:** так. Замість форми з'явилося повідомлення «Дякуємо! Заявку отримано…». Тестові дані синтетичні (`test.lead@example.com`, вигадане ім'я й телефон, `https://example.com` лише текстом у полі).
- **Консоль (за звітом агента):** 0 помилок, 0 попереджень; два звичайні інформаційні повідомлення режиму розробки.
- **Мережа (за звітом агента):** окрім файлів сторінки, один запит `POST http://localhost:3000/` → `200 OK` (Server Action), відповідь `{"status":"ok"}`; решта 21 запит — ресурси самої сторінки. Журнал `npm run dev` це підтверджує: `POST / 200 in 157ms`. Інших адрес агент не відкривав.
- **Чого не перевірено:** чи з'явився лід у дашборді (для цього потрібен вхід на `/login`, його не просили). Дані застосунку лежать у пам'яті процесу (`lib/db.ts`).
- **Артефакти:** Playwright записав знімки й журнал у `.playwright-mcp/`; тека в `.gitignore`, `git status` її не показує.
